# Screenshots Checklist — SlothOps AI

Use this checklist when preparing screenshots for the DEV submission or README.

## Required Screenshots

- [ ] **Hero / Landing** — App open with no files, showing the dark navy/cyan hero title and sidebar
- [ ] **Sidebar — Ollama Online** — Green "Ollama Online" badge, model selector showing gemma:2b
- [ ] **Sidebar — Fallback Mode** — Red "Ollama Offline" badge + heuristic-mode caption  
- [ ] **Upload Tab** — File uploader with 3 sample files dropped in
- [ ] **Analysis Results — Meeting Notes** — Expanded analysis card with category badge, summary, action items, proposed filename
- [ ] **Analysis Results — Research** — Expanded card for vector_db_research.txt
- [ ] **Duplicate Warning** — The orange/red duplicate-candidate panel showing similarity score
- [ ] **Review & Apply Tab** — Checkboxes with destination preview paths
- [ ] **Applied Successfully** — Green success toast after copy operation
- [ ] **Undo Operation** — Info message after clicking Undo Last
- [ ] **Operation History Panel** — Expanded operation log with ✅ and ↩️ icons
- [ ] **History Tab** — Session history entries with timestamps, applied status
- [ ] **History — Clear** — Confirmation after clearing all history
- [ ] **About Tab** — Feature list, stack chips, privacy section
- [ ] **Heuristic Mode Analysis** — Analysis result card showing "⚡ Heuristic mode" badge

## Optional / Bonus

- [ ] Side-by-side before/after: chaotic filenames → organised folder structure
- [ ] Output folder in File Explorer showing Category subdirectories
- [ ] Animated GIF of the full workflow (upload → analyse → review → apply)

## Capture Instructions

1. Set browser window to 1440×900 for consistent framing
2. Use a dark desktop wallpaper to match the app aesthetic
3. For the sidebar screenshots, ensure the sidebar is expanded
4. Name files: `screenshot_01_hero.png`, `screenshot_02_sidebar_online.png`, etc.
5. Place files in `docs/screenshots/` directory
